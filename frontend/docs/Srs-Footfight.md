# **FoodFighter** 

# **ที่มาและความสำคัญ (Statement of Problems)**

ในปัจจุบันการเลือกรับประทานอาหารร่วมกันของกลุ่มเพื่อนหรือครอบครัวมักใช้เวลานาน เนื่องจากสมาชิกแต่ละคนมีความต้องการและข้อจำกัดที่แตกต่างกัน เช่น งบประมาณ ประเภทอาหารที่ชื่นชอบ อาหารที่แพ้ ข้อจำกัดทางศาสนา หรือข้อจำกัดด้านสุขภาพ ส่งผลให้การตัดสินใจเลือกร้านอาหารเป็นเรื่องที่ยุ่งยากและใช้เวลามาก

ดังนั้นจึงได้พัฒนา  **FoodFighter** ซึ่งเป็นระบบช่วยตัดสินใจเลือกเมนูอาหารสำหรับกลุ่ม โดยใช้ AI วิเคราะห์เงื่อนไขของสมาชิกทุกคน และแนะนำเมนูที่เหมาะสมที่สุด พร้อมค้นหาร้านอาหารที่เกี่ยวข้องและแสดงผลบนแผนที่ เพื่อช่วยลดเวลาในการตัดสินใจและเพิ่มความสะดวกในการเลือกร้านอาหารร่วมกัน

# **วัตถุประสงค์**

* เพื่อช่วยให้กลุ่มผู้ใช้งานสามารถตัดสินใจเลือกเมนูอาหารร่วมกันได้ง่ายขึ้น  
* เพื่อใช้ AI วิเคราะห์เงื่อนไขและความต้องการของสมาชิกแต่ละคน  
* เพื่อค้นหาร้านอาหารที่ตรงกับเมนูที่แนะนำและแสดงบนแผนที่  
* เพื่อช่วยลดเวลาที่ใช้ในการตัดสินใจเลือกร้านอาหาร

# **ขอบเขตของระบบ (Scope)**

ผู้ใช้งานสามารถสมัครสมาชิกและเข้าสู่ระบบ โดยผู้ใช้งานครั้งแรกจะต้องกรอกข้อมูลพื้นฐานด้านอาหาร (Food Profile) ซึ่งเป็นข้อมูลเฉพาะตัวที่ไม่เปลี่ยนแปลงบ่อย เช่น อาหารที่แพ้ ข้อจำกัดทางศาสนา และรูปแบบการรับประทานอาหาร เพื่อใช้เป็นเงื่อนไขพื้นฐานในการวิเคราะห์เมนู

ผู้ใช้งานสามารถสร้างห้องสำหรับเลือกอาหาร หรือเข้าร่วมห้องผ่าน Room Code หรือ Invite Link หรือ qr code  เมื่อเข้าสู่ห้อง สมาชิกสามารถกด Ready เพื่อยืนยันว่าพร้อมเข้าร่วม Session เมื่อสมาชิกทุกคนพร้อม หัวหน้าห้องสามารถกด Start เพื่อเริ่ม FoodFight

หลังจากเริ่ม Session สมาชิกแต่ละคนจะกรอกความต้องการสำหรับมื้อนั้น (Meal Preference) เช่น งบประมาณ ประเภทอาหารที่อยากกิน เมนูที่ไม่อยากกิน หรือความต้องการเพิ่มเติม

เมื่อสมาชิกทุกคนกรอก Meal Preference เรียบร้อยแล้ว ระบบจะนำข้อมูลดังกล่าวมาวิเคราะห์ร่วมกับ Food Profile ของสมาชิกแต่ละคน และใช้ AI แนะนำเมนูที่เหมาะสมที่สุด 2  รายการ

สมาชิกสามารถตอบ OK หรือ Pass สำหรับแต่ละเมนู และระบบจะประมวลผลการโหวตเพื่อหา Final Menu ตามเงื่อนไขที่กำหนด หากไม่มีเมนูที่ผ่านเกณฑ์ ระบบสามารถแนะนำเมนูใหม่ได้

หลังจากได้ Final Menu ระบบจะค้นหาร้านอาหารที่เกี่ยวข้องกับเมนูดังกล่าว พร้อมแสดงตำแหน่งบนแผนที่ ข้อมูลร้าน ระยะทาง เวลาเปิด–ปิด และข้อมูลติดต่อ (หากมี)

เว็บไซต์นี้ประกอบด้วยคุณสมบัติหลัก ดังนี้

* สมัครสมาชิกและเข้าสู่ระบบ  
* กรอกและแก้ไข Food Profile  
* สร้างห้อง (Create Room)  
* เข้าร่วมห้องผ่าน Room Code หรือ Invite Link หรืิอ qr code  
* Lobby และแสดงสมาชิกภายในห้อง  
* Ready Status ของสมาชิก  
* Head เริ่ม Session (Start FoodFight)  
* กรอก Meal Preference หลังเริ่ม Session  
* AI วิเคราะห์ Food Profile และ Meal Preference  
* AI แนะนำเมนู 2 รายการ  
* OK / Pass Voting  
* Final Vote และ Tie Break  
* Recommend Again ได้ 1  รอบ  
* แสดง Final Menu  
* ค้นหาและแสดงร้านอาหารบนแผนที่  
* เลือกร้านอาหาร  
* ประวัติการเลือกอาหาร

## **การเตรียมความพร้อม**

* สมาชิกสามารถกด Ready เพื่อแสดงว่าพร้อม   
* ระบบแสดงสถานะ Ready ของสมาชิกทุกคนแบบ Realtime  
* หัวหน้าห้องสามารถเริ่มได้โดยกดปุ่ม start เมื่อสมาชิกกด ready   
* ในกรณีที่สมาชิกกด Ready ไม่ครบ  หัวหน้าห้องสามารถกด start ได้ถ้ามีสมาชิกกด ready อย่างต่ำ 60% หลังจากผ่านไป 2 นาที โดยนับจากสมาชิกคนแรกกปุ่ม ready   
* เมื่อ Head เริ่ม Session สมาชิกที่มีสถานะ Ready จะถูกกำหนดเป็น Active Member และสามารถกรอก Meal Preference และเข้าร่วมการโหวตได้ ส่วนสมาชิกที่ยังไม่ Ready จะสามารถติดตาม Process และผลลัพธ์ของ Session ได้ แต่ไม่สามารถกรอก Meal Preference หรือเข้าร่วมการโหวตใน Session นั้นได้

  ## **การวิเคราะห์ด้วย AI**

AI จะทำหน้าที่

* วิเคราะห์ Food Profile และ Meal Preference ของ **Active Member ทุกคน**  
* สรุปข้อจำกัดของ Active Member ภายในกลุ่ม  
* แนะนำเมนูที่เหมาะสมที่สุด **2 รายการ**  
* อธิบายเหตุผลในการเลือกแต่ละเมนู  
* แสดงข้อควรระวัง เช่น อาหารที่แพ้ หรือข้อจำกัดด้านอาหาร  
* ต้องไม่แนะนำเมนูที่ขัดกับ Must-have Conditions ของ Active Member

### **Recommend Again และ Final Vote**

* หากไม่มีเมนูใดได้รับ OK อย่างน้อย 60% ในการโหวตรอบแรก ระบบสามารถ Recommend Again ได้ 1 ครั้ง  
* AI จะแนะนำเมนูใหม่จำนวน 2 รายการ โดยต้องไม่ซ้ำกับเมนูที่แนะนำในรอบแรก  
* Active Member ทำการ OK หรือ Pass เมนูทั้ง 2 รายการในรอบใหม่  
* หากมีเมนูผ่านเกณฑ์ 60% ระบบดำเนินการเลือก Final Menu ตามเกณฑ์ปกติ  
* หากไม่มีเมนูใดผ่านเกณฑ์ 60% อีกครั้ง ระบบจะเข้าสู่ Final Vote  
* ระบบนำเมนูทั้ง 4 รายการจากการแนะนำรอบแรกและรอบ Recommend Again มาเป็นตัวเลือกใน Final Vote  
* Active Member แต่ละคนต้องเลือกเมนูที่ต้องการเพียง 1 รายการ  
* เมนูที่ได้รับคะแนน Final Vote สูงสุดจะเป็น Final Menu  
* หากเมนูที่มีคะแนนสูงสุดมีคะแนนเท่ากัน ให้ Head เป็นผู้ตัดสินจากเมนูที่มีคะแนนสูงสุดร่วมกัน
